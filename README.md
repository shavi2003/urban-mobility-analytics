# urban-mobility-analytics

## Overview

This project investigates urban mobility patterns using year-long transportation sensor datasets collected from over 100 monitoring locations.

The project combines data preprocessing, feature engineering and statistical modelling to analyse travel behaviour and extract insights from large-scale transportation data.

## My Contributions

This repository showcases my individual contributions to a collaborative University of Bristol Engineering Mathematics project.

My work included:

- Data preprocessing
- Feature engineering
- Statistical analysis
- Data visualisation
- Interpretation of modelling results

## Dataset

The dataset consists of year-long transportation sensor measurements collected from over 100 urban monitoring locations.
